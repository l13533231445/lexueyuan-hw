# 乐学园晚托作业辅导工作台 · 云端共享版

老师自建的**多手机同步**版：3 台手机（或平板）打开同一个链接，录入的作业 / 周回访 / 试卷
会自动汇总到同一份数据，**每 8 秒自动互相同步**，一份数据保存 **4 个月**（超期自动清理）。

## 功能（与原本地版一致）
- 功能1 作业拍照登记 + 图上文字备注（红色）+ 完成勾 + 补充任务 + 当晚学情
- 功能2 每周回访（自动汇总本周作业生成草稿，待回访 / 已回访）
- 功能3 试卷分析 + 成绩等级 A/B/C/D
- 按学生名字统一归档；作业记录保存后弹图片预览（可下载）

## 技术说明
- 后端：`server.js`，**零依赖**，只用 Node 内置模块（`http` / `fs` / `crypto`）。
- 存储：服务端一个 `db.json`（JSON 文件，带写锁防并发损坏）。
- 同步：前端打开后每 8 秒向后端比对版本号，数据变化且当前未在输入框打字时自动刷新当前页。
- 留存：启动与每日执行一次清理，删除 `date` 早于 120 天（约4个月）的作业 / 回访 / 试卷记录。
- 端口：`process.env.PORT`（默认 3000）；数据目录：`process.env.DATA_DIR`（默认 `./data`）。
- 访问密码：所有 `/api/*` 需携带正确密码（请求头 `x-access-key`）。**默认密码 `lexueyuan2026`**，
  前端首次打开会要求输入，输入正确后本地记住，之后免输；密码改了会提示重新登录。
  **部署时务必用环境变量 `PASSWORD` 改掉默认密码**（见下方部署示例）。

## 访问密码（安全）
- 改默认密码：设置环境变量 `PASSWORD=你的强密码`。
  - 本地：`PASSWORD=你的强密码 node server.js`
  - Render：在 Blueprint / 环境变量里加 `PASSWORD`，值设为你的密码。
  - Railway / Fly.io / Koyeb：在平台的环境变量设置里加 `PASSWORD`。
- 若忘记密码：改 `PASSWORD` 环境变量重新部署，再用新密码登录（前端旧密码会自动失效并提示重输）。
- 注意：公开链接 + 密码只能防“随手进入”，不是强鉴权；链接不外泄给无关人即可。

## 本地运行（自测）
```bash
cd 乐学园晚托作业辅导工作台-云端版
node server.js
# 浏览器打开 http://localhost:3000
```

## 部署到免费托管平台（拿到可分享链接）
### 方案 A：Render（推荐，最简单）
1. 把这个文件夹推到你的 GitHub 仓库。
2. 打开 https://render.com → New → Blueprint → 选择该仓库 → 用本目录的 `render.yaml`。
3. 部署完成后，Render 会给一个 `https://xxxx.onrender.com` 公开链接。
4. 把链接发到 3 台手机的微信/群里，用浏览器打开即可同步使用。
   - 持久化：配置里已挂 `/var/data` 磁盘（Render 磁盘为付费项）。若不开磁盘，
     数据在“重新部署”时会重置，但日常重启保留；要真正 4 个月不丢，建议开磁盘或用方案 B。

### 方案 B：Railway / Fly.io / Koyeb
- 均支持 Node 项目，`startCommand: node server.js`，端口 `PORT`。
- 这些平台多提供免费额度与持久卷，更适合长期保存 4 个月数据。

### 方案 C：Supabase（最稳的持久化，免费额度友好）
- 若担心数据丢失，可把 `server.js` 的存储换成 Supabase Postgres（需账号+密钥）。
- 前端无需改动，仍是调用 `/api/*`。需要我改可继续说。

## 注意事项
- 链接是公开可访问的，但已加访问密码（默认 `lexueyuan2026`，部署时务必用 `PASSWORD` 改掉）。
  老师内部 3 台手机使用没问题；密码不外泄给无关人即可。
- 图片以 base64 存在 `db.json` 里，单条作业含照片，长期量大时文件会增长；
  4 个月留存会自动裁剪旧记录，缓解膨胀。
